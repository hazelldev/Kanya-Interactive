# Privacy Policy – Kanya Interactive Bot

Terakhir diperbarui: [05]

Kebijakan ini menjelaskan data yang diproses oleh bot RPG Kanya Interactive ("Bot").

**Data yang diproses:**
- ID user, ID server, dan ID channel saat kamu memakai command.
- Data progres permainan, seperti level, pengalaman, inventaris, dan mata uang dalam game.
- Isi command yang kamu kirim ke Bot.

**Penggunaan:** menjalankan fitur RPG, menyimpan progres permainan, membuat channel atau pengaturan yang diperlukan di server, serta menjaga keamanan layanan.

**Penyimpanan:** data progres disimpan selama Bot aktif di server atau sampai kamu meminta penghapusan.

**Pembagian:** data tidak dijual dan tidak dibagikan ke pihak ketiga, kecuali jika diwajibkan hukum.

**Penghapusan:** kamu dapat meminta penghapusan data progres kamu, atau mengeluarkan Bot dari server kapan saja.
